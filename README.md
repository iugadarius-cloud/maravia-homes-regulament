# Maravia Homes regulament

Site in Romanian for guests to sign the house rules. The signed PDF is emailed to **iuga.darius@icloud.com**.

## Public link (GitHub Pages)

After you push this repo and enable Pages (Settings → Pages → Deploy from a branch → `main` / `docs`), the site is:

`https://YOUR-USERNAME.github.io/maravia-homes-regulament/`

The first emailed agreement asks FormSubmit to confirm the iCloud address — open that email and click confirm. After that, every signature arrives with the PDF attached.

## On this Mac

```bash
python3 server.py
```

Then open http://localhost:3000
